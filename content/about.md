Rheton is a voice AI interviewer for software engineers. It runs mock interviews that feel like the real thing, so the first time you hear a hard follow-up question isn't in the room that counts.

## What we build

Rheton talks to you like an interviewer would. It asks about the role you're applying for and the projects on your resume, watches you work, and pushes back when an answer is vague.

There are two tracks:

- **Algorithmic.** Coding problems in a live editor, in your language, followed by a code review and real follow-up questions.
- **Real-World Engineering.** A small repository with a failing test suite, an editor and a terminal. You debug, implement or extend real code while the interviewer asks how you got there.

Every session ends with a written summary of what went well and what to work on next, and you can rerun the same session later to see how you've improved.
