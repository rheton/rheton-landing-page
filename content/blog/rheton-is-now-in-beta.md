Rheton is now open for early access, free while we're in beta.

Rheton is a voice interviewer for engineering interview prep. You talk to it the way you'd talk to a real interviewer, it watches the code as you write it, and it pushes back on your assumptions instead of reading off a script.

## What a session looks like

Set up takes a minute: upload your resume, paste the job description you're prepping for, and pick which rounds you want: coding, technical questions, behavioral, or any mix, in any order, repeated as many times as you like.

For a coding round, the flow has four steps. You talk through your approach before writing anything, then implement it in a live editor while the agent watches and runs your code. From there it walks through your submission with you, covering edge cases and possible bugs, before closing with a couple of follow-up questions that probe the real-world constraints your solution quietly assumed away. Technical and behavioral rounds are fully voice, the latter scored STAR-style.

If you go quiet, it checks in rather than assuming you're done. If you're stuck mid-problem, it offers hints on a schedule instead of watching you flounder. And it's paced against however long you told it the session should run.

At the end, you get a written summary: what you did well, where you struggled, what to work on next. Run the same setup again later to see if it's better.

## What's live in this beta

- Coding, technical, and behavioral rounds, freely ordered and repeated
- A live code editor with real sandboxed execution the agent can see and run
- Resume- and job-description-aware questions, not generic prompts
- A natural voice model, not a robotic TTS read of a script
- A written summary at the end of every session
