# CLAUDE.md

Guidance for working in this repo (Hugo static site for the Rheton landing page).

## Blog content rules

- Avoid dashes in blog post body copy (`content/blog/*.md`). This covers both the literal double hyphen (`--`) and the em dash (`—`). They're overused as a crutch for run-on sentences. Default to a period and a new sentence, or a comma, instead. If a piece of copy truly needs one, use no more than one em dash per paragraph.
